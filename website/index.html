Every root cause, proven from the source.

Cauzon is an AI agent that diagnoses data incidents. It walks DataHub lineage upstream, ranks the culprits, and only blames a table when it can show the verifiable path — then writes the dossier back so the next person, or agent, inherits it.

        The problem
        
The 2 a.m. question

        
"The revenue dashboard is wrong. Why?"

      

      

        

          
🚨

          
Alerts tell you that

          
Observability tools fire when a metric moves. They stop there — you still trace the cause by hand.

        

        

          
🕳️

          
Agents hallucinate

          
Without grounded context, an LLM invents a plausible cause it can't back up. Guesses pollute the catalog.

        

        

          
⏱️

          
Humans burn hours

          
Click through lineage, diff schemas, read SQL — a fire drill that repeats every single incident.

        Capabilities
        
Engineered to be trusted

      

      

        
🧭
Origin-seeking
Blames the upstream origin, not the intermediate victim that merely inherited the symptom.

        
🔗
Path-grounded
Every claim carries a verifiable lineage path. No path, no diagnosis.

        
✍️
Writes back
Contributes the finding to the graph — the highest-value behavior a data agent can have.

        
🧱
Backend-agnostic
Identical agent logic over a zero-infra mock or a live DataHub via the MCP Server.

        
🛡️
Index-resilient
Falls back to raw lineage aspects when the graph index lags. RCA keeps working.

        
📱
Web + mobile
A Next.js PWA you can install on your phone, with a live reasoning trace.
